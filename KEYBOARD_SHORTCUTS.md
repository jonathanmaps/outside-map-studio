# Keyboard Shortcuts

Shortcuts work globally unless you're typing in an input or editor. Press **`?`** in the app at any time for help.

## Main Shortcuts

| Key | Action |
| --- | --- |
| `⌘K / Ctrl+K` or `/` | Command palette |
| `O` | Open style |
| `E` | Export style |
| `D` | Data sources |
| `S` | Settings |
| `G` | Global state |
| `J` | JSON editor |
| `!` | Debug |
| `C` | Copilot |
| `T` | Timeline |
| `W` | Workspace |
| `I` | Toggle inspect mode |
| `M` | Focus map |
| `F` | Find layers |
| `[` / `]` | Previous / next layer |
| `V` | Toggle selected layer visibility |
| `X` | Isolate selected layer |
| `?` | Shortcut help |

## Undo / Redo

| macOS | Windows / Linux | Action |
| --- | --- | --- |
| `⌘Z` | `Ctrl+Z` | Undo |
| `⌘Shift+Z` | `Ctrl+Y` | Redo |

## Command Palette

Use **`⌘K / Ctrl+K`** or **`/`** to search actions, panels, dialogs, and layers by name. This is the fastest way to navigate without memorizing every shortcut.

## Timeline

Open with **`T`**, then use the panel controls to **preview, restore, export, delete, or compare** checkpoints. Select two checkpoints to enter Compare view.

## Useful Input Keys

- **Enter** — confirm coordinate jumps and other focused actions.
- **Esc** — leave the current input or close/cancel where supported.
- Shortcuts are intentionally ignored while typing so they don't interfere with text entry.

## Quick Workflow

**Open (`O`) → Find (`F`) → Edit → Checkpoint (`T`) → Compare → Export (`E`)**

For AI-assisted styling, open **Copilot (`C`)** to explore palettes, moods, accessibility, contrast, and cleanup tools.
