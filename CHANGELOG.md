# Changelog

## main

### Features & improvements
- Added coordinate jumping and preserved manually entered map URL hashes.
- Added layer search, map-only layer focus/isolation, and resizable editing panels.
- Replaced Cypress with Playwright E2E testing and added Vitest browser/unit coverage.

### Bug fixes
- Add current fixes here.

## 3.1.0

### Highlights
- Added hillshade color arrays and relief-color elevation expressions.
- Added globe/mercator projection control.
- Added markdown style-spec documentation and global-state editing.
- Upgraded to CodeMirror 6 and added full-style JSON editing.
- Improved local style opening, file upload, scrolling, headers, errors, and editor behavior.
- Added sprite-object support, clearer layer icons, problematic-property highlighting, and root-relative style URLs.

## 3.0.0

### Highlights
- Upgraded to MapLibre GL JS 5, Vite 6, Cypress 14, and OpenLayers 10.
- Added German translation, raster `tileSize`, tile scheme options, local file-system editing, and LocationIQ support.
- Migrated drag-and-drop to dnd-kit and autocomplete to Downshift.
- Modernized React APIs and improved duplicate-layer/network/storage error handling.

## 2.x

- Added GitHub release workflows and desktop build updates.
- Upgraded MapLibre to v4 and introduced continuous deployment.
